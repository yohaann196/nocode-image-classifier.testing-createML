# ShapeClassifier

A small Core ML image classifier created with Apple Create ML.  
This model classifies simple shapes:  

**Supported shapes:** circle, kite, parallelogram, rectangle, rhombus, square, trapezoid, triangle.

---

## Files in this repository

- `ShapeClassifier.mlmodel` – The trained Core ML model (44 KB).  
- `README.md` – This file.

---

## Usage

You can use the model directly in your app or Xcode Playground.

---

## Notes

- The model only works with the 8 shapes listed above.  
- No `.mlproj` file or dataset is included.  
- The repo is lightweight and ready to use.
